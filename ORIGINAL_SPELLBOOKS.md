# Original magic owned by a character

The workshop can draft a spell for the hero or a present, willing NPC companion who has a real spellcasting foundation. The selected caster's class, level and own slot capacity guide the model. Each effect has a strict type and a power budget. An invalid response gets at most one explicit format repair; a second invalid response is shown as a refusal. Drafting does not cast, teach, heal or advance time.

Learning adds one owned definition and a journal record. The hero's existing `createdSpells` book stays compatible; NPC books live in their persistent companion records. A registration operation ID prevents repeated requests from adding another entry and rejects a different owner/definition under the same ID. Revision checks prevent stale learning. Registration never restores HP, slots, items or money. The current workshop is an explicit authorship tool, not an implemented training-time/cost system. Caps are200 hero entries and32 per NPC.

`original-spell-spec.cjs` is a shared pure schema/power validator with no ID creation or I/O. The app's synchronous validation facade mints IDs. `original-spell-actions.ts` supplies pure preflight and one synchronous interpreter for human and NPC casters. It checks the actual caster/turn/budget, own slots, target existence/life, range, cover and charm before dice or costs. Real costs precede readied reactions and Counterspell. Conditions, expiry, concentration replacement/checks and healing use core helpers. An original Counterspell level comes from a validated full definition; an unknown string alone cannot pretend to be a spell level.

An exact NPC order uses `combat.action|bonus.cast_created_spell.SPELL.TARGET`. Only its owner's book supplies options. The bridge contains the one queued definition per caster, with at most3 entries and10000 JSON characters; it does not copy all books into combat flags. On the actual NPC turn the same interpreter resolves one attempt, using that NPC's resources and the real engine RNG. A consumed or refused attempt is not silently replaced. The ordinary saved result protocol and journal persist the outcome. Cancelling or consuming an order clears its bridge.

The intent menu remains at most4800 serialized characters and24 entries per NPC, prioritizing named spells. Context keeps hero definitions separate from a small query-selected NPC book window inside the existing12000-character budget. Dialogues and questions cannot execute these definitions merely by describing a cast.
