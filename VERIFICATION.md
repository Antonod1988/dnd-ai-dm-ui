Генерация проверена подставным ответом API; настоящая генерация требует настройки и живой проверки. Подробности: [ARTWORK.md](ARTWORK.md).

- Мастер может оформить новую идею игрока отдельной ручной проверкой `alternativeFor`. Успех засчитывает ту же цель, сохраняя старые попытки; самостоятельное условие ключа остаётся обязательным. Обход через обычный бросок с совпавшим ID закрыт. Неизвестные ссылки, циклы и недостижимые зависимости ключей отклоняются.
- Для неверного формата/схемы намерения, мира или описания допускается одна ограниченная коррекция. Перед изменением проверяется весь новый проект мира; действие/бросок/награда не повторяются. Сетевой сбой не запускает цикл коррекций. Неудачное описание сохраняет диагностические данные локально и остаётся доступно для явного повтора.

## Исправления

- Переключение вкладок не создаёт бой и не восстанавливает HP.
- Непонятный локальный текст вызывает уточнение.
- Кнопки оставшихся действий больше не скрыты повтором первых шести.
- После успешной атаки живой враг получает ответный ход.
- Герой с 0 HP не продолжает атаковать; есть явно обозначенная упрощённая помощь.
- Защитная магия требует доступного заклинания и расходует ячейку. Отдых применяется явным действием и переводит день.
- Другие стартовые сценарии не подменяются именами и местом первой истории.
- Одновременные запросы не перезаписывают друг друга.
- Локальный HTTP-сервер отклоняет посторонние Origin/Host и не раздаёт приватные файлы.
- В UI показана выбранная модель, есть индикатор ожидания, текст ввода сохраняется при ошибке, обновляются число записей и состояние героя.
