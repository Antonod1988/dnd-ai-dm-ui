# Проверка 2026-10-11

Восстановлена отдельная версия интерфейса из `dnd-ai-dm-ui-mockup`; архив и прежние сохранения не изменялись.

## Подтверждено

- Локально проходят 20 тестов, smoke игрового цикла и проверка синтаксиса.
- GitHub Actions проверяет Windows/Linux и Node 20/22. Первый запуск выявил несовместимость glob-путей Node 20 на Windows; запускатель исправлен, следующая матрица прошла целиком. Проверки последнего коммита доступны во вкладке Actions.
- Реальный OAuth выполнен в существующем Chrome пользователя, с его самостоятельным подтверждением MFA и разрешений.
- JWT проверен через официальные ключи OpenAI; разрешение на использование плана получено, список моделей загружен из аккаунта.
- После перезапуска локального сервера вход и выбранная модель сохранились.
- Реальный ход со свободным текстом завершён на GPT-6.1-Sol: AI определил доступное действие, написал ответ, обновились журнал и сохранение.
- Затем по просьбе пользователя выбрана GPT-6-Luna. Реальный ход осмотра сцены завершён на Luna с броском и повествованием; состояние сохранено.
- Ошибка формата первого реального intent-ответа устранена: явный JSON-контракт и проверка action ID. Несуществующие действия отклоняются; частичные изменения при ошибке не сохраняются.
- Код опубликован отдельным публичным MIT-репозиторием. Личные сохранения, заметки, ключи и OAuth-токены исключены; проверялись имена и содержимое подготовленных файлов.

## Исправления

- Переключение вкладок не создаёт бой и не восстанавливает HP.
- Непонятный локальный текст вызывает уточнение.
- Кнопки оставшихся действий больше не скрыты повтором первых шести.
- После успешной атаки живой враг получает ответный ход.
- Герой с 0 HP не продолжает атаковать; есть явно обозначенная упрощённая помощь.
- Защитная магия требует доступного заклинания и расходует ячейку. Отдых применяется явным действием и переводит день.
- Другие стартовые сценарии не подменяются именами и местом первой истории.
- Одновременные запросы не перезаписывают друг друга.
- Локальный HTTP-сервер отклоняет посторонние Origin/Host и не раздаёт приватные файлы.
- В UI показана выбранная модель, есть индикатор ожидания, текст ввода сохраняется при ошибке, обновляются число записей и состояние героя.

## Ограничения

В этом Chrome локальная страница после OAuth показывала `ERR_BLOCKED_BY_CLIENT`. Сам callback был обработан, вход подтверждён; UI и реальные ходы проверялись в браузере Codex. Настройки защиты Chrome не менялись.

Это рабочий прототип текстовой игры с ограниченным набором действий, не полная D&D 5e. Карта, полноценные death saves, рост уровня и произвольные механики магических предметов остаются за пределами версии. Полный список границ находится в README.

## Продолжающееся развитие: проверка основы

- Теперь проходят 40 тестов, smoke и синтаксическая проверка.
- Подключён зафиксированный независимый снимок ядра SRD, без изменений соседнего проекта. Проверено создание 108 сочетаний из 12 основ классов и 9 происхождений, реальные проверки навыков, отдых и загрузка SQLite после повторного открытия.
- Проверены оригинальные генерируемые заклинания: разрешение схемы, ограничение силы, реальное лечение, расход ячейки, запрет неизвестной цели/кастера без ресурсов и замена концентрации.
- Внебоевые проверки сохраняют попытку: успешная История открывает факт, неуспешная Проницательность не раскрывает секрет; повторный триггер не бросает кубик заново.
- Симуляция 400 ходов сохраняет все записи журнала и архив сообщений. Контекст модели остаётся в лимите 10 000 символов; зацепка из начала истории находится по релевантному запросу. Это ограничение контекста, не утверждение о точном количестве токенов или проценте экономии.
- Показания usage, если провайдер их возвращает, берутся из завершённого ответа; оценка по символам помечается отдельно.
- На живом UI и GPT-6-Luna проверен диалог двух компаньонов: разные реплики Элессы и Рована, затем реплика игрока. Обсуждение не изменило номер игрового хода или HP. Отмена будущих реплик и отсутствие автоматического исполнения предложения также покрыты тестами.
- Исследован локальный OpenMAIC и записаны решения по диалогам и возможному кооперативу. Код AGPL не импортировался. Комнаты, приглашения и удалённое подключение ещё не реализованы.

Новая база правил доступна через `/api/dnd/*`, но основной игровой экран ещё использует прежний поток альфы. Полноценное объединение нового движка, генерации мира, квестов, карты, социальных и survival-систем остаётся активной работой, а не завершённым результатом.
